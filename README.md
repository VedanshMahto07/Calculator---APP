# 🧮 Calculator App

A simple and responsive calculator built using HTML, CSS, and JavaScript.

This project performs basic arithmetic operations and helped me strengthen my 
understanding of JavaScript logic, DOM manipulation, and event handling.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear (AC) functionality
- ⌫ Delete (DEL) functionality
- 🚫 Operator validation
- ⚡ Interactive button hover effects
- 📱 Clean and responsive UI

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

---

## 📖 About the Project

This calculator project was created to improve frontend development fundamentals 
and strengthen JavaScript concepts such as:

- DOM Manipulation
- Event Listeners
- Conditional Logic
- String Handling
- Functions
- Error Handling

The project focuses on both functionality and user interaction while keeping the UI simple and clean.
